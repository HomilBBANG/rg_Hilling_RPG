힐링 판타지 RPG(가칭, Godot 프로젝트명 **Denial**)의 Godot 프로젝트입니다. P0(고정 탑다운 + 3D 픽셀화 렌더,
데드셀풍 D 스타일) 위에 **P1 코어 플레이 루프**를 올렸습니다: 야외 지역 1곳에서 전투 → 시체 조사 → 중량 인벤토리 →
캠핑카 운전·실내·창고·수면 → 사망/복귀 → 검은 고양이 동행·교감. 기획 기준은 [`docs/GDD.md`](docs/GDD.md) **v10.6**와
[`docs/CAT_COMPANION_HANDOFF.md`](docs/CAT_COMPANION_HANDOFF.md)이며, 미정 사항을 임시로 정한 값은
[`notes/IMPLEMENTATION_ASSUMPTIONS.md`](notes/IMPLEMENTATION_ASSUMPTIONS.md)에 모두 적었습니다(정식 규칙 아님).

> **`지도` 탭**에서는 지역 지도(`data/maps/<지역>.json`)를 만든다: 바탕 지형은 지역 데이터에서 자동으로 그려지고(출구·체크포인트·마을은 흐리게 참고 표시), 그 위에 **지명·아이콘(마을·야영지·동굴·상점·위험·의뢰·길 안내·볼거리·물가·강한 적)·메모**를 클릭으로 놓고 끌어서 옮긴다. 지도 이름·지도 화면 순서·설명, **얻는 방법**(상점 + 값 / NPC + 메모 — 실제로 주는 건 대화 탭의 액션 `지도 주기` / **필드 드롭** — `보이는 지역`을 바꿔 다른 지역 지도 위에서도 위치를 찍음). 검증·실행 취소·저장
> **`몬스터 AI` 탭**에서는 몬스터가 무엇을 할지 정하는 **결정 그래프**(`data/ai/*.json`)를 노드로 고칩니다: 시작 → **조건**(싸우는 중인가·주인공이 가까운가·덮칠 수 있는가·주인공을 놓쳤는가·**공격 준비됐는가**·자리에서 멀어졌는가·체력이 낮은가·같은 종족이 불렀는가·빈 캠핑카가 가까운가·밤인가·확률, 각각 예/아니오 출력) → **싸움 시작**(같은 종족 부르기 켜고 끄기) → **행동**(어슬렁거리기·쫓아가기·덮치기 공격·**독액 뱉기·물기·할퀴기·가시 세우고 돌진**·도망치기·자리로 돌아가기·가만히 있기·캠핑카 공격). 거리·초 같은 설정은 오른쪽 속성 패널, **시뮬레이션** 탭에서 조건마다 예/아니오를 고르면 지나가는 길이 밝아지고 고르는 행동이 바로 보임. 왼쪽 아래 **몬스터별 AI**에서 몬스터마다 쓸 그래프와 **선공** 여부를 골라 `이 몬스터에 적용`(= `data/monsters.json`의 그 몬스터 항목만 고침). 몬스터는 한 번 뛸 때마다 그래프를 따라가 처음 닿는 행동을 함

> **새 게임 컷씬:** `새 게임` → **인트로**(삽화+내레이션, 현실에서 TRPG 세계로 — 임시 문안·삽화 자리표시) → **오프닝**(게임 화면 안,
> 영화 띠, 주인공 놀람 표정) → 조작 시작. 새 캐릭터는 **진행 단계 A(혼자, 고양이·캠핑카 없음)**로 시작하고, 퀘스트 **"왕을 만나라"**가 붙음 → 교역소에서 북쪽 길로 **왕도** → 북쪽 **성 정문**으로 들어가면 **왕의 알현실** → 옥좌 앞에서 `E`로 왕과 대화 → 보상(골드·빵·물약)과 함께 **"드래곤 토벌"** 퀘스트 수락. 그 뒤 초원 길가에 **검은 고양이**가 나타나 기다리고, 다가가면 **인게임 장면**(영화 띠 → 고양이가 다가와 마주 봄)과 **대화**가 이어지고(그동안 주인공은 움직일 수 없음) 끝나면 동행 시작 — 선택지 "쓰다듬어 본다"(호감도 +5) / "미안, 갈 길이 멀어" 어느 쪽이든 따라옴(GDD 2.3 순서). **드래곤의 둥지로 가는 길**: 고원 북쪽 길(솔방울 마을 근처 갈림길에서 북쪽) 끝 → **잿빛 산길**(★★★, 160×220 m, 재 덮인 굽잇길·바위 슬라임·**불씨 슬라임**) → 도착하면 퀘스트 목표 1 완료, 중간의 **불탄 짐수레**(흔적), 길 끝 **드래곤의 둥지 입구**(붉게 빛나는 구덩이)에 닿으면 목표 2 완료·지도에 표시. 구덩이 앞에서 `E` → **드래곤의 둥지**(★★★★, 용암 틈·금화 더미·뼈, 입구 바위 틈 = 쉼터) → 보물 더미 위에서 자던 **드래곤**이 가까이 가면 깨어나 **먼저 말을 건다** — **싸워서는 이길 수 없다**(칼은 비늘에 튕겨 나감, 상처 0). **대화로 설득해 둥지에서 내보내야 함**: 잘못 답하면("네 목을 베러 왔다!", "금화를 가져가겠다", "왕이 시켰으니까", "네가 알아서 해") 화가 나서 한동안 공격(물기·꼬리·화염 — **바닥에 붉은 범위가 먼저 보이고 밖으로 걸어 나가면 피함**), 쉼터로 물러나거나 시간이 지나면 진정 → 가까이 가서 `E`로 다시 대화. 잘 답하면(이야기하러 왔다 / 마을 사람들이 무서워한다 / 바다 건너 다른 대륙) **드래곤의 비늘 한 장**(다시 만나자는 약속)을 남기고 **날아올라 바다 쪽으로 떠남** → 떠나는 장면 → 퀘스트 목표 완료, 둥지는 빈 채로 남음(이 드래곤은 다른 대륙에서 다시 만남). → **왕도 알현실에서 왕에게 보고**("말로 내보냈어요") → 소원 선택("캠핑카를 주세요!" / "조금만 생각해 볼게요" = 나중에 다시) → **성 앞 광장의 소원 의식**(왕·궁정 마법사 엘라·경비병) → 주문과 함께 **하늘에서 캠핑카가 떨어져 왕이 깔림**(먼지·화면 흔들림·굴러 나오는 왕관) → 경비병 "시해범이다, 잡아라!" → **수배**, 퀘스트 **"왕도 탈출"**: 주인공은 캠핑카 운전석에 있고 경비병 6명이 쫓아옴(처음 3초는 넋을 놓고 서 있음) — **멈추거나 느리게 가다 경비병이 붙으면 붙잡혀 광장에서 다시**, **남문(초원으로 가는 길)에 닿으면 탈출** → 탈출 장면(수배 전단, "이 섬에는 더 있을 수 없다", **— 챕터 1 끝 —**) → 캠핑카와 함께 초원 북쪽 길 끝으로. 이후 **왕도·알현실로는 다시 갈 수 없음**(길·빠른 이동 모두 "수배 중"). 지금 맵 전체가 챕터 1 튜토리얼 섬이고, 챕터 2는 바다 건너 다른 대륙(준비 중). 대사는 모두 임시 문안 `E`/`Space`/클릭 다음, `ESC` 건너뛰기. 삽화는 `assets/cutscenes/intro_01~04.png`

## P1에서 해 볼 수 있는 것

| 흐름 | 방법 |
|---|---|
| 전투 | 마우스 방향 클릭 1회 = 1회 공격(SP 4). 무기 영역이 닿아야 판정 → d20 명중 → 별도 치명 굴림 → 1d4 피해. 풀밭 슬라임(캠프 동쪽)·숲 슬라임(북동쪽 숲). **슬라임은 모두 비선공** — 먼저 덤비지 않고, 때리면 그 한 마리만 반격(같은 종족도 끼어들지 않음), 주인공이 멀어지거나 자리에서 14 m 넘게 쫓아오면 돌아가 회복. 예전 선공 동작(다가가면 덤빔·같은 종 합류·빈 캠핑카 긁기)은 지우지 않고 그래프 `ai.slime.aggressive`로 남아 있어서, `몬스터 AI` 탭에서 선공을 켜면 그대로 돌아옴 |
| 초원 짐승 3종 | 바람결 초원에 슬라임이 아닌 몬스터. **공격 전에 바닥에 붉은 범위가 먼저 보이고, 밖으로 걸어 나가면 피함**(드래곤과 같은 방식), 맞으면 d20 명중 판정. 기술을 쓰는 동안은 맞아도 끊기지 않음. **식충식물**(북동쪽 큰 호수 동쪽 둔치 2 · 북쪽 숲 가장자리 1): 뿌리박혀 움직이지 않고, 7.5 m 안에 오면 **독액 뱉기** — 주인공이 선 자리에 붉은 원 → 독액이 날아가 떨어질 때 원 안이면 명중 판정, 맞으면 **중독**(6초, 1.5초마다 HP −1, HP 막대가 초록·"중독 n초", 건강 HLT가 높을수록 짧음, 독으로는 쓰러지지 않음, 잠·부활로 풀림). **늑대**(남서쪽 숲, 2마리 무리): 선공 — 7 m 안에 오면 덤비고 14 m 안의 무리를 부름, 걸어서 빠르게 쫓아옴(달리면 따돌릴 수 있음). **물기**(앞의 작은 원 → 몸을 날려 물기) / **할퀴기**(앞 부채꼴 → 앞발로 크게 할큄)를 반반. 자리에서 20 m 넘게 멀어지면 포기. **고슴도치**(캠프 북쪽 풀밭 2 · 서쪽 1): 비선공 — 때리면 몸을 말아 가시를 세우고 붉은 길을 띄운 뒤 그 길로 **굴러 돌진**(몸에 닿으면 명중 판정, 밀려남), 끝나면 잠깐 어지러움. 재충전 중엔 물러나 거리를 벌림. 전리품: 독액 주머니·약초 / 늑대 가죽·송곳니 / 고슴도치 가시·산딸기 |
| 전투 로그 | 좌하단. `G`(또는 클릭)로 1 아이콘 → 2 한 줄 → 3 상세(주사위·계산식) |
| 시체 조사 | 처치한 자리의 시체 앞에서 `E` → 원하는 것만 "가져가기"/"모두"/"전부 가져가기". 게임 시간 60분 뒤 사라짐 |
| 중량 | `Tab` 소지품(게임은 계속 진행). **가방 + 착용 장비를 모두 합쳐** 30kg 초과 시 느려지고 45kg을 넘기는 획득은 거부. 캠프의 **보급 상자**(철광석)로 시험 |
| 미니맵 | 화면 **오른쪽 위**. 주변 지형(큰 지도와 같은 그림, 북쪽이 위)과 **가운데 빨간 화살표 = 나**(바라보는 방향). **파란 ■ = 세워 둔 캠핑카**, **노란 점 = NPC**(집에 들어간 NPC는 안 보임), ● 도시, ▲ 가 본 체크포인트, ◆ 찾은 이야기 장소, ◉ 동굴 입구, 흰 점 = 지역 출구, 붉은 점 = 근처 몬스터(싸우는 중이면 진하게). 고양이는 표시하지 않음. 아래에 지역 이름·위험도. **휠 = 확대/축소, 클릭 = 큰 지도(M)**. 캠핑카 실내·변덕의 미궁에서는 숨김, 대화·컷씬 중에도 숨김. 퀘스트 추적은 미니맵 아래로 옮김 |
| 소지품·장비 창 | `Tab` / `C` / `K` = 한 창의 세 탭(위쪽 **소지품·장비** / **능력치** / **스킬**, 탭 클릭으로도 전환). 능력치 탭에는 레벨업·능력치·세부 능력치만, 스킬·생활 기술은 스킬 탭(아래 `K`). 왼쪽: **장비 칸**(등·머리·목걸이 / 허리띠·몸·반지1 / 장갑·신발·반지2 / 주무기·보조무기), 그 아래 **소지 중량 막대**(노란 선 = 느려지기 시작, 막대 끝 = 한계)와 숫자, 선택한 아이템의 설명·버튼(장착·해제·사용·읽기·퀵슬롯 1~4·배치·주유/수리). 오른쪽: **가방 칸** 7열(최소 7×7, 칸 제한 없음 — 많아지면 아래로 늘어남), 아래 **정렬**(장비 → 소모품 → 재료 → 캠핑카 용품 → 소품, 같은 종류는 이름순). 칸 위에 마우스 = 설명창(무게·효과·설명), 클릭 = 선택, **더블클릭 = 바로 장착/사용/해제** |

## 최신 버전 받기 (git pull)

Godot 에디터는 프로젝트를 열거나 대화 에디터로 저장할 때 `project.godot`·`data/dialogues/*.json` 같은 파일을 스스로 다시 씁니다.
그 상태에서 같은 파일이 바뀐 커밋을 받으면 git이 "local changes would be overwritten"으로 멈춥니다. 처음 한 번만 아래를 실행해 두면
`git pull`이 로컬 변경을 잠깐 치워 두었다가 받은 뒤 다시 얹어 주므로 더 이상 멈추지 않습니다(정말로 같은 줄을 서로 다르게 고쳤을 때만 충돌 표시).

```bat
cd C:\Game\denial
git config merge.autoStash true
git pull
```

## 렌더 구조 (P1 재사용 대상)

```
bootstrap (Node)
├─ PixelRenderController (Control)        scripts/visuals/pixel_render_controller.gd
│   ├─ SubViewport  ← 3D 월드(야외/실내)가 여기서 저해상도로 렌더
│   └─ TextureRect  ← nearest 필터, 정수 배율 확대, 서브텍셀 오프셋
└─ CanvasLayer → VisualHud                ← 고해상도 UI (픽셀화 영향 없음)
```

- **픽셀 스냅 카메라** (`scripts/visuals/topdown_camera.gd`): 고정 각도(피치 50°) 직교 카메라가 렌더 텍셀
  격자에 위치를 맞추고, 남는 서브텍셀 오차는 TextureRect를 화면 픽셀 단위로 밀어 보정합니다(1텍셀 여백 렌더).
  배경은 떨리지 않고 스크롤은 부드럽게 유지하는 표준 기법입니다.
- **M2**는 Godot 4.7의 `Viewport.scaling_3d_mode = SCALING_3D_MODE_NEAREST`를 사용합니다.
- **픽셀 외곽선** (`shaders/pixel_outline_post.gdshader`): 카메라에 붙은 전체 화면 쿼드가 저해상도 렌더의 깊이·노멀 버퍼를
  읽어, 앞 물체의 경계 텍셀을 어둡게(색 있는 외곽선), 단단한 소품의 볼록 모서리를 밝게 칠합니다. 지형·풀(roughness 1.0)과
  잎·바위(0.93)는 하이라이트에서 제외합니다.
- **색보정** (`shaders/pixel_grade.gdshader`): 업스케일 TextureRect에서 텍셀 단위로 스플릿 토닝·채도·비네트(+선택 디더).
- **스타일라이즈드 재질** (`scripts/world/stylized_materials.gd`): 지형·잎·바위·풀 셰이더와 절차적 노이즈 텍스처.
- 낮/밤: `scripts/visuals/day_night_controller.gd`, 오토로드 `Game`(`scripts/core/game.gd`)이 시계·라이트 상태 보관.
- 가림 실루엣: `shaders/occluded_silhouette.gdshader` (`depth_test_inverted` + 자기 가림 방지 바이어스).

P1에서는 `PixelRenderController`, `TopdownCamera`, `DayNightController`, 실루엣 셰이더를 그대로 가져가고
`visual_lab.gd`/`camper_interior_lab.gd` 같은 월드 스크립트만 교체하면 됩니다.

## 알려진 문제 / 미검증

- **실제 GPU에서 실행하지 않았습니다.** 검증은 클라우드 컨테이너의 소프트웨어 렌더러(Mesa llvmpipe, Vulkan
  Forward+ 및 OpenGL Compatibility)에서 했습니다. FPS 수치(8~30)는 소프트웨어 렌더 기준이라 의미가 없습니다.
- **대화 에디터**는 실제 Godot 4.7.2 에디터 안에서 자동 점검(대화·컷씬·몬스터 AI·지도 탭 44개 항목 통과)했지만, 가상 디스플레이(xvfb)라 **마우스 드래그·연결 조작감은 직접 확인**이 필요합니다. 에디터를 열면 Godot가 `project.godot`를 다시 써서(기본값 줄 정리) diff가 생길 수 있습니다 — 동작에는 영향 없음.
- 픽셀 외곽선은 Forward+ 전용이며 Compatibility에서는 자동으로 꺼집니다(디오라마 버전은 Compatibility에서 미검증).
- 이동 중 픽셀 떨림은 녹화 영상의 프레임으로만 확인했습니다. **실시간 체감은 직접 실행해서 판단**해 주세요.
- Forward+와 Compatibility의 밤 밝기가 다릅니다(Compatibility가 더 밝고 헤드라이트 빔이 더 뚜렷함).
- 창 크기를 1920×1080이 아닌 크기로 바꾸면 `canvas_items` 스트레치 때문에 픽셀이 비정수 배율로 늘어납니다.
- 1080p 전환 이전에 찍은 `captures/` 이미지(p0_baseline, visual_direction, sprite_pipeline)는 1280×720 기준입니다. 최신 화면은 `captures/hd_1080p/`.
- **P1 스프라이트 베이크 시간**: 캠핑카를 16방향으로 구우면서 첫 로딩·렌더 프리셋(F1~F4) 변경 시 소프트웨어
  렌더러에서 약 16초 걸렸습니다(GPU에서는 훨씬 짧을 것으로 예상, 미검증). 그동안 3D 모델이 그대로 보이며,
  한 번 구운 시트는 실내/야외 전환 때 재사용합니다.
- P1 흐름은 자동 투어(직접 호출 + 시뮬레이션 키 입력)로만 확인했습니다. 마우스 조준 감각, 전투 난이도, 운전 조작감은
  직접 플레이해서 판단해 주세요. 주인공에게 무기 모델은 아직 없습니다(외형 변경은 승인 후 진행).
