# 컷씬 삽화

인트로 같은 전체 화면 컷씬의 삽화를 여기에 넣습니다. 1920×1080(16:9) 기준으로, 비율이 달라도 화면을 꽉 채우도록 잘립니다.

| 파일 | 쓰는 곳 |
|---|---|
| `intro_01.png` | 인트로 — 어린 시절, 친구 넷이 모여 TRPG |
| `intro_02.png` | 인트로 — 어른이 되어 멀어짐 |
| `intro_03.png` | 인트로 — 회사가 문을 닫음 |
| `intro_04.png` | 인트로 — 낡은 룰북을 찾음 |

파일이 없으면 게임에서 "삽화 자리 — 파일 이름" 카드가 대신 나옵니다. 다른 이름을 쓰려면 대화 에디터의 컷씬 탭에서 그 단계의 그림 파일을 바꾸면 됩니다.
