# Claude Code — 캠핑카 운전 조작 개선 (GDD v10.3)

> 이 문서는 `GDD.md`의 **9.7 캠핑카 운전 조작**을 실제 Godot 프로젝트에서 검증하기 위한 구현 요약이다. 기획 원본이 우선한다.

## 목표

현재 캠핑카 운전의 답답함·회전 불편·미끄러짐을 개선한다. 현실적인 자동차 물리보다 **고정 탑다운 WASD 자동 조향**의 편안한 조작감을 우선한다. 기존 그래픽, 고양이, 연료, 고장·수리, 차량 내부 출입, 지역 이동 시스템은 손상시키지 않는다.

## 작업 순서

1. 현재 차량 씬과 이동 컨트롤러 입력, 물리 노드, 충돌체, 카메라 구조를 분석한다. 문제 원인을 요약한다.
2. 차량 탑승 중 `WASD = 화면 기준 목표 이동 방향`, `Space = 제동`, `R = 누르는 동안 저속 수동 후진`을 구현한다. 기본 조향은 차량이 목표 방향을 향해 회전한 뒤 앞으로 이동하도록 구성한다. 차체가 횡방향으로 미끄러지는 표현은 금지한다.
3. 목표 방향 전환 시 회전과 가속도를 분리하여 프레임 독립적으로 제어한다. 저속에서는 좁은 회전 반경, 고속 급회전 중에는 일시적인 속도 보정을 적용한다. 키를 놓으면 짧게 감속하고 제동은 더 강하게 한다.
4. 현실 차량 물리 구현이 불편함의 주요 원인이라면 단순 아케이드 이동 컨트롤러로 교체한다. 단, 엔진 노드 교체는 기존 차량 기능 손상 위험을 검토한 뒤 수행한다.
5. 임시 값: 최고속도 6 m/s, 가속도 14 m/s², 자연감속 20 m/s², 제동감속 35 m/s², 최대 회전 480°/s, 후진 3 m/s. 전부 Inspector에서 조정 가능하게 export 한다. 최종 밸런스라고 주장하지 않는다.
6. Space 우선, R 후진 우선, 나머지 WASD 목표 방향 순서로 입력 충돌을 정리하는 것을 초기 가정으로 한다. 후진 중 A/D 저속 방향 수정은 실제 시운전으로 확인한다.
7. 카메라 회전은 금지한다. 픽셀 렌더링의 서브픽셀 떨림을 확인하고 필요시 최종 출력 픽셀 스냅과 시각적 카메라 추적을 구분한다.
8. 기존 주행과 신규 주행을 동일 필드에서 비교한다. 최소 정지 출발·90도 회전·U턴·장애물 통과·충돌 후 탈출·브레이크·픽셀 지터·내구도 0 운행 금지를 검증한다.

## 완료 조건

- 조향 입력이 지체 없이 반응한다.
- 좌우 방향 전환에 큰 곡선이나 긴 역주행이 필요하지 않다.
- 차가 옆걸음치듯 미끄러지지 않는다.
- 운전 중 카메라가 회전하지 않는다.
- F 외부 라이트, 연료 소모, 내구도·수리, 실내 출입, 빠른 이동 등의 기존 기능을 깨지 않는다.
- 변경 파일 목록, 실행 검사 결과, 스크린샷 또는 테스트 영상(실제 생성했을 때만), 조정 가능한 튜닝 변수 표, 남은 문제점을 보고한다.

**유의:** 이 작업은 현재 시점의 운전 조작 개선이다. 게임 전체 GDD 재설계, 새로운 콘텐츠 추가, 아트 리소스 재제작은 작업 범위가 아니다. 사소한 튜닝 수치는 질문하지 말고 임시값으로 시험한 후 비교 결과를 보여준다.
