# 신수 검은 고양이 — Claude Code 구현 참고 (v10.2)

> 이 파일은 `GDD.md` 확정 사항의 개발 전달용 요약이다. 구현 세부가 필요한 경우 **미정 규칙을 임의로 확정하지 말고** 개발 가정으로 처리한다. P0 그래픽 검증 우선순위는 변경하지 않는다.

## 확정 사건 흐름

1. 이세계 도착: 플레이어 단독 여행.
2. 왕에게 용 토벌 퀘스트를 받고 출발.
3. 검은 고양이 신수가 스스로 접근해 주인공을 간택하고 추종하기 시작.
4. 고양이와 동행하며 용을 처치, 왕의 소원으로 캠핑카 획득.
5. 캠핑카 실내에 들어갈 때마다 고양이를 만날 수 있고, 쓰다듬기 및 간식 주기로 교감 가능.

## 복귀 장소 판정 — 규칙

| 조건 | 복귀 위치 | 필수 연출/조건 |
|---|---|---|
| 캠핑카 미보유 | 사망 위치와 가까운 안전 체크포인트 | 체크포인트에는 몬스터 없음 |
| 캠핑카 미보유 + 고양이 동행 중 | 위와 같음 | 기상 시 고양이가 곁에 있거나 주변에서 움직이는 등 구출한 정황 연출 |
| 캠핑카 보유 | 캠핑카 내부 | 신수가 구출해 준 설정 유지 |

고양이와 아직 합류하지 않은 구간에도 가까운 체크포인트로 복귀한다. 이 구간에서 고양이가 구조했다는 연출을 보여줄지는 **미정**.

### 전리품 손실과 복귀를 분리

- 일반 필드 및 고정 던전: 고블린이 전리품 일부를 가져가고 나머지는 사망한 현장에서 회수 가능.
- 랜덤/로그라이크 던전: 해당 탐험 중 획득한 전리품 전부 손실(입장 전 장비·성장 유지).
- 복귀 위치만 달라질 뿐, 기존 전리품 손실 방식은 바뀌지 않음.

## 고양이 생활·교감 규칙

- 캠핑카 획득 후 **실내에 고양이가 항상 나타나야** 한다.
- 상호작용을 통해 **쓰다듬기** 가능.
- **간식 주기** 가능. 간식 제공은 **호감도 상승**에 연결.
- 외부에서는 플레이어를 따르는 기존 동행 서사 유지. 장면 전환 시 고양이 실내/실외 배치가 중복되지 않게 한다.
- 쓰다듬기 시 호감도 상승 **여부**, 호감도 효과, 간식 사용량, 애니메이션 종류는 **미정**.

## 최소 기능 검증 항목 [제안 — 구현 가정]

- 용 토벌 퀘스트 출발 구간에서 고양이 동행 플래그 변화 확인.
- 캠핑카 획득 전 사망 → 유효한 안전 체크포인트로 복귀.
- 캠핑카 획득 후 사망 → 캠핑카 실내로 복귀.
- 고양이 동행 후 복귀 시 구출을 암시하는 고양이 배치/행동 확인.
- 캠핑카 실내에서 쓰다듬기 입력을 수용하고 피드백을 제공.
- 캠핑카 실내에서 간식을 주면 호감도 데이터가 상승.
- 실내외 고양이 오브젝트 중복/유실 없음.
- 이전에 확정한 죽음 시 전리품 손실이 달라지지 않음.

## 추후 설계할 사항 [미정]

체크포인트 선택 거리 산정과 지역 경계 처리, 체크포인트 목록/표시, 초기 합류 전 구조 연출, 호감도 상한/효과, 간식 종류와 비용, 고양이 실내 스케줄·자리, 쓰다듬기 효과, 애니메이션 상세, 동물 변신/전투 참여.
