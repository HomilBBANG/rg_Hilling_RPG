# 힐링 RPG — 통합 기획 및 Claude Code 전달 패키지

이 폴더의 파일들은 2026-10-20까지 확정된 게임 기획을 한데 모은 문서이며, **아직 실제 Godot 프로젝트 소스코드는 포함하지 않습니다.** 실행 게임은 Claude Code가 제작합니다.

## 파일 목록

| 파일 | 용도 |
|---|---|
| `GDD.md` | 지금까지 확정된 세계관·시스템의 통합 기획서(v10.0) |
| `GRAPHICS_PROTOTYPE.md` | 1차 최우선 작업: 3D 픽셀 렌더링과 분위기 검증용 P0 명세 |
| `CLAUDE_CODE_HANDOFF.md` | Claude Code에 통째로 붙여 넣을 첫 개발 요청 |

## 추천 진행 순서

1. 세 문서를 Claude Code 프로젝트 폴더에 복사한다.
2. `CLAUDE_CODE_HANDOFF.md`의 **요청 프롬프트**를 붙여 넣는다.
3. Claude Code가 만든 Godot 프로젝트에서 **P0 시각 프로토타입부터 실행**한다.
4. 저해상도 A/B, 낮/밤, 캠핑카 야외/실내를 확인한다.
5. 원하는 화면이 가능한지 확인한 후에 P1 전투·캠핑카 루프를 구현한다.

## 핵심 주의

- `GDD.md`의 **[확정]**은 기획자의 승인 없이 수정하지 않는다.
- **[미정]**은 아직 결정한 내용이 아니며 구현용 임시값을 쓴 뒤 문서에 기록한다.
- 오래된 턴제 전투 기획을 구현하지 않는다.
- 캠핑카는 생활 경험치로 업그레이드하지 않는다.
- 시각 품질 검증을 RPG 전체 시스템 개발보다 앞세운다.
