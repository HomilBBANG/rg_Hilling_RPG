# 힐링 RPG — GDD / Claude Code 패키지 v10.2

본 패키지는 사용자가 확정한 힐링 RPG 전체 기획과 최신 신수 검은 고양이 설계를 담습니다. 실행 가능한 Godot 게임 소스 자체는 포함되지 않습니다.

## 문서

- `GDD.md`: 최신 통합 GDD v10.2 (기존 v10.1 규칙 유지 + 안전 체크포인트·구출 연출·교감 추가)
- `CAT_COMPANION_HANDOFF.md`: 고양이 동행, 사망 후 복귀, 체크포인트, 간식 호감도 개발 요약
- `GRAPHICS_PROTOTYPE.md`: 초기 P0 그래픽 검증 명세(기존 문서)
- `CLAUDE_CODE_HANDOFF.md`: 초기 P0 그래픽 검증 개발 지시(기존 문서)

## v10.2 변경 사항

1. 캠핑카 획득 전 사망: 사망 지점과 가까운 몬스터 없는 안전 체크포인트에서 깨어남.
2. 고양이 합류 이후 체크포인트 기상: 곁에 있는 고양이/주변 동작 등을 통해 구조한 정황 표현.
3. 캠핑카 획득 후 사망: 신수의 구출로 캠핑카 내부에서 기상하는 기존 규칙 유지.
4. 캠핑카를 얻은 후: 실내에서 고양이를 항상 만날 수 있음.
5. 고양이 쓰다듬기 및 간식 주기 인터랙션, 간식을 주면 호감도 상승.
6. 사망 시 기존 필드·던전별 전리품 손실 규칙 유지.

## 개발 참고

최신 확정 기획은 `GDD.md`를 기준으로 하며, 그 외 구체 수치·조건은 [미정]이다. GDD의 사용자 미승인 제안을 자동으로 확정하지 말 것. P0 그래픽 검증 우선순위는 유지하며, 고양이의 실질 구현은 게임 플레이 시스템 제작 단계에서 진행해도 된다.
