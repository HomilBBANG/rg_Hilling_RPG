# 대화 에디터 (Dialogue Editor) — 사용법과 구조

`docs/DIALOGUE_EDITOR_HANDOFF.md`(v10.5)에 따라 만든 **노드형 대화 에디터**입니다. 대사·선택지·조건·액션·컷씬
호출을 코드 없이 작성하고, 에디터 안에서 미리보기·검증하고, 실제 게임에서 바로 실행할 수 있습니다.
UI 형태(Godot `EditorPlugin` + `GraphEdit`), 데이터 포맷, 단축키는 핸드오프의 **제안안을 구현한 개발용 초기안**이며
사용자 승인 전입니다.

![대화 에디터](../captures/dialogue_editor/editor_03_preview_choice.png)

## 여는 법

1. Godot 4.7 에디터로 프로젝트를 엽니다: `Godot.exe --path C:/Game/denial -e` (또는 프로젝트 매니저에서 열기).
2. 화면 위쪽 **2D · 3D · Script · Game … 옆의 `Dialogue`** 탭을 누릅니다.
   - 탭이 안 보이면: 프로젝트 → 프로젝트 설정 → 플러그인 → **Dialogue Editor** 사용 체크.

## 작업 흐름 (핸드오프 5장)

| 단계 | 방법 |
|---|---|
| 새 대화 / 열기 | `새 대화` → `dialogue_id`(예: `dialogue.npc.rosa.rain`)와 제목 입력. 왼쪽 목록에서 클릭해 열기. 검색창은 ID·제목·태그·화자 이름·**대사 본문**까지 찾음. 목록 아래에 화자별 대화 수 |
| 노드 추가 | 위쪽 `대사 / 선택지 / 조건 / 액션 / 컷씬 호출 / 종료` 버튼 — **선택한 노드의 빈 출력에 자동으로 이어 붙음**. 그래프 오른쪽 클릭, 출력 점에서 빈 곳으로 선을 끌어 놓아도 추가 |
| 연결 | 출력 점(오른쪽) → 입력 점(왼쪽)으로 끌기. 출력 하나에는 대상 하나(다시 연결하면 교체). 끊기: 입력 쪽 선 끝을 오른쪽 클릭으로 끌기 |
| 편집 | 노드를 클릭하면 **오른쪽 속성 패널**에서 편집(그래프에는 1~2줄 미리보기만). 대사는 여러 줄 입력·붙여넣기 가능, 화자·퀘스트·아이템·컷씬은 목록에서 고름(오타 방지). 노드 ID는 바꿔도 연결 유지 |
| 미리보기 | `▶ 미리보기`(처음부터) / `▶ 선택 노드부터`. 아래 미리보기 탭에서 대사 진행·선택지 클릭, 현재 노드는 그래프에서 **노란색으로 강조**, 지나온 경로와 액션 기록 표시. 오른쪽 **테스트 상태**(퀘스트 상태·플래그·골드·소지품)를 바꿔 조건별 결과 확인 — 실게임·세이브에는 영향 없음. **끝나면 '왜?' 설명**(2026-10-25): 지나온 조건마다 예/아니오와 **[예로 바꿔 다시 보기]** 버튼(테스트 상태를 그 조건에 맞게 고치고 처음부터 재생), 이어지지 않은 출력·가려진 선택지도 글로 알려 줌 — "미리보기가 안 된다"는 대부분 조건이 아니오라서 대사 없이 끝난 경우 |
| 플래그·이벤트 | 조건 '플래그가 켜져 있다', 액션 '플래그 설정', 종료 노드의 완료 이벤트, 조건 '이벤트 완료됨'은 **플래그 고르기 칸**: 목록(모든 플래그 + 뜻 + 출처)에서 고르거나 새 이름을 적으면 아래에 **켜는 곳·쓰는 곳**이 바로 표시됨. 도구 줄의 **`플래그 목록`** 버튼 = 전체 표(게임 코드·대화·컷씬·지역 이야기 장소·퀘스트 목표). 출처 모음은 `scripts/game/flag_catalog.gd` |
| 도움말 | 모든 탭 도구 줄의 **`❓ 도움말`** = 그 탭 쓰는 법(쉬운 말, `addons/dialogue_editor/editor_help.gd`). 도구 줄 아래 한 줄 안내(① → ② → …). 태그 칸 설명: 목록 검색용 꼬리표, 게임에 영향 없음 |
| 검증 | `검증` → 검증 탭. 항목을 클릭하면 해당 노드로 이동. 오류가 있는 노드는 제목에 ⚠ |
| 저장 | `저장` / **Ctrl+S** → `res://data/dialogues/<dialogue_id>.json`. 오류가 있으면 확인 후 저장 가능(작성 중 초안). 덮어쓰기 전 이전 내용을 `user://dialogue_backups/<id>/`에 백업(최근 20개), 파일이 에디터 밖에서 바뀌었으면 덮어쓰기 전에 물어봄 |
| 게임에서 실행 | `▶ 게임에서 실행` → 저장 후 게임을 켜고, 로딩이 끝나면 그 대화를 **실제 대화창·실제 게임 상태**로 재생 |
| NPC에 연결 | `data/speakers.json`의 `"talk"` 값을 대화 ID로 바꾸면 그 NPC에게 `R`로 말을 걸 때 열림 — **GDScript 수정 불필요** |

단축키: Ctrl+S 저장 · Ctrl+Z / Ctrl+Y(또는 Ctrl+Shift+Z) 실행 취소·다시(입력 칸 밖에서) · Delete 노드 삭제 ·
Ctrl+C / Ctrl+V 복사·붙여넣기(내부 연결 유지, 새 ID) · Ctrl+D 복제 · `정렬` 자동 배치 · 드래그로 다중 선택.

## 컷씬 탭 (`Dialogue` 화면 위쪽 `대화 | 컷씬`)

인트로 같은 **그림+내레이션 컷씬**과 게임 화면 안의 **인게임 컷씬**을 같은 방식으로 만듭니다. 컷씬은 단계 목록이고,
게임은 그 순서대로 재생합니다(카메라는 고정 탑다운 그대로).

![컷씬 탭](../captures/dialogue_editor/editor_10_cutscene_intro.png)

| 할 일 | 방법 |
|---|---|
| 새 컷씬 / 열기 / 복제 | `새 컷씬` → `cutscene_id`(예: `cutscene.story.dragon_offer`)와 제목. 왼쪽 목록에서 열기(★ = 새 게임 때 재생). `복제`는 다른 ID로 복사 |
| 단계 추가 | `단계 추가 ▾`에서 종류 선택 → **선택한 단계 다음에** 들어감. `▲ ▼`로 순서, `단계 복제`, `단계 삭제`(Delete) |
| 편집 | 단계를 클릭하면 오른쪽에서 편집. 화자·표정·인물은 목록에서 고르고, 삽화는 `찾기…`로 파일 선택(미리보기 그림 표시) |
| 미리보기 | `▶ 미리보기` / `▶ 선택 단계부터`(단계 두 번 클릭도 같음). 아래 화면에서 삽화·내레이션(한 자씩)·초상화 대사·페이드·영화 띠·자막이 재생되고, 클릭 또는 E/Space로 넘김. 인물 이동·바라보기·플래그는 글로만 표시 |
| 검증 | 빈 문장, 등록 안 된 화자·인물, 없는 표정, 아직 없는 그림 파일(경고 — 게임에선 자리표시) |
| 저장 | Ctrl+S → `data/cutscenes/<cutscene_id>.json`, 덮어쓰기 전 백업, 밖에서 바뀌면 확인, Ctrl+Z/Y 실행 취소 |
| 새 게임 순서 | 왼쪽 아래 "새 게임 때 재생": `+ 지금 컷씬`, `▲ ▼`, `빼기` → `data/story.json`. 새 게임을 누르면 이 순서대로 재생 |
| 게임에서 실행 | `▶ 게임에서 실행`(이 컷씬) / `▶ 새 게임 순서 실행`(인트로부터 전부) |
| 대화에서 부르기 | 대화의 `컷씬 호출` 노드 → 속성 패널의 `컷씬 탭에서 편집` 버튼으로 바로 이동 |

### 단계 10종

| 단계 | 하는 일 |
|---|---|
| 화면 페이드 | 어둡게(암전)/밝게, 시간. 컷씬이 검은 화면으로 끝나면 자동으로 다시 밝아짐(새 게임 순서 중간은 다음 컷씬이 밝힘) |
| 삽화 | 전체 화면 그림(16:9로 채움, `assets/cutscenes/`). 비우면 내림. 없는 파일은 "삽화 자리" 카드 |
| 내레이션 | 화면 가운데 띠에 한 자씩. 키 → 바로 다 보임 → 한 번 더 → 다음. 자동 넘김 시간도 지정 가능 |
| 대사 | 초상화 대화창(주인공 왼쪽·상대 오른쪽, 말 안 하는 쪽 50%), 화자·표정·대사 |
| 자막 | 화면 아래 짧은 자막, 표시 시간 |
| 대기 | 시간 |
| 영화 띠 | 위아래 검은 띠 켜기/끄기 (인게임 컷씬용) |
| 인물 이동 | 주인공·고양이(걸어감)·NPC(바로 이동)를 다른 인물 옆 또는 좌표로. 자기 자신을 고르면 지금 자리에서 그만큼 걸어감 |
| 인물 바라보기 | 누가 누구를 봄 |
| 플래그 설정 | 진행 플래그 켜기/끄기 (대화 조건에서 사용) |

게임에서: E/Space/클릭 = 다음, **ESC = 컷씬 건너뛰기**("ESC로 건너뛸 수 있음"을 켠 컷씬만). 건너뛰어도 플래그·인물 위치·마지막 화면은
끝까지 재생한 것과 같게 적용됩니다. 컷씬 동안 조작 잠금, HUD 숨김.

## 몬스터 AI 탭 (`대화 | 컷씬 | 몬스터 AI`)

몬스터가 한 번 뛸 때마다 무엇을 할지 정하는 **결정 그래프**(`data/ai/<ID>.json`, 런타임 `scripts/game/monster_ai.gd`)를 고칩니다.

- **왼쪽 위**: AI 그래프 목록, `새 AI`(빈 그래프 또는 기존 것 복사). **왼쪽 아래**: 몬스터별 AI — 몬스터를 골라 쓸 그래프(또는
  "선공 여부로 기본")와 **선공** 체크 → `이 몬스터에 적용` = `data/monsters.json`의 그 몬스터 블록만 고침.
- **가운데**: 노드 그래프. 노드 4종 — **시작**(하나, 못 지움) · **조건**(예/아니오 출력) · **싸움 시작**(싸우는 중으로 바꾸고, 처음이면
  같은 종족을 부를 수 있음) · **행동**(끝, 출력 없음). 출력 점을 끌어 잇고, 오른쪽 클릭으로 끊고, Delete로 지움. `정렬`은 시작부터 단계별 배치.
- **오른쪽**: 속성 — 조건/행동 종류 고르기, 설명, 설정값(거리·초·비율, 범위 안에서만), ID 이름 바꾸기(연결 유지). 노드를 안 고르면 그래프 이름·설명과 이 AI를 쓰는 몬스터 목록.
- **노드 종류**: 조건 11가지(… 주인공을 놓쳤는가 · **공격 준비됐는가** · …), 행동 11가지(어슬렁거리기 · 쫓아가기 · 덮치기 공격 ·
  **독액 뱉기 · 물기 · 할퀴기 · 가시 세우고 돌진**(초원 짐승의 기술 — 바닥에 붉은 범위를 먼저 띄움; 그 기술이 없는 몸이면 덮치기) ·
  도망치기 · 자리로 돌아가기 · 가만히 있기 · 캠핑카 공격). 기술 수치(준비 시간·범위·피해·중독)는 `data/monsters.json`의 `attacks`.
- **아래 시뮬레이션**: 조건 11가지마다 예/아니오 체크 → 지나가는 길의 노드가 밝아지고 고르는 행동·"싸우는 중이 됨/같은 종족을 부름"이 표시됨. **검증**: 연결 없는 출력, 없는 노드로의 연결, 시작이 하나가 아님, 고리, 닿지 않는 노드(경고).
- 저장 `Ctrl+S`, 실행 취소 `Ctrl+Z` / 다시 `Ctrl+Y`, `파일에서 다시 읽기` = 변경 버리기. 오류가 있는 그래프도 저장은 되지만 게임은 그 그래프 대신 예전 규칙으로 움직이고 경고를 남깁니다.

## 지도 탭 (→ 2026-10-24부터 맵 에디터 `Map` 화면의 `지도 표시물` 탭, [`MAP_EDITOR.md`](MAP_EDITOR.md))

지역 지도(`data/maps/<지역>.json`, 런타임 `scripts/game/map_db.gd`)를 만듭니다. 플레이어는 처음에 지도가 없고 지역마다 지도를 모읍니다.

- **왼쪽**: 지도를 둘 수 있는 지역 목록(지도 파일이 없으면 고를 때 새로 만듦).
- **가운데**: 그 지역의 지형(지역 데이터에서 자동) + 참고용 출구·체크포인트·마을(흐리게). 위쪽 `지명`/`아이콘`/`메모`를 누른 뒤 지도를 클릭하면 그 자리에 표시가 생기고, 표시를 클릭해 고르고 끌어서 옮김(Delete = 지우기). `보이는 지역`은 다른 지역에 떨어뜨릴 지도 위치를 찍을 때만 바꿈.
- **오른쪽**: 지도 이름(지도 화면·상점에 보임), 지도 화면 순서, 설명. 고른 표시의 종류·아이콘·글자·좌표. **얻는 방법**: `+ 상점`(상점·값 — 그 상점 목록에 바로 나옴), `+ NPC`(누가·메모 — 실제로 주려면 대화 탭에서 그 NPC 대화에 액션 **지도 주기**를 넣음), `+ 필드 드롭`(지역 + `지도에서 위치 찍기` — 게임에서 그 자리에 두루마리가 놓임).
- **아래**: 검증(없는 상점, 겹친 ID, 알 수 없는 아이콘, 얻을 방법 없음 등). 저장 `Ctrl+S`, 실행 취소 `Ctrl+Z` / 다시 `Ctrl+Y`.

## 퀘스트 탭 (`대화 | 컷씬 | 몬스터 AI | 퀘스트`)

퀘스트 정의(`data/quests/<quest_id>.json`, 런타임 `scripts/game/quest_db.gd` / `quest_manager.gd`)를 만듭니다. 전에는 JSON을 손으로 고쳤습니다.

- **왼쪽**: 퀘스트 파일 목록(메인 이야기 → NPC 의뢰 → 게시판 → 현장 사건 순, 제목·ID·종류). `새 퀘스트` = ID(`quest.`로 시작하는 파일 이름)와 제목을 넣으면 바로 파일이 생김(대화 탭의 퀘스트 목록에도 바로 뜸).
- **오른쪽 위**: 제목·설명, **종류**(NPC 의뢰 / 게시판 의뢰 / 현장 사건 / 메인 이야기)와 **의뢰인**(화자 목록), **받는 방식**(직접 수락 / 자동 시작), 반복 가능·완료 시 모은 아이템 넘김·임시 데이터, 제한 시간. 종류마다 "받는 길"(어느 탭의 어떤 액션으로 시작·보고하는지)을 한 줄로 알려 줌.
- **목표 ID**를 바꾸면 그 목표를 올리는 대화 액션('퀘스트 목표 진행')의 참조도 같이 바뀌어 저장됨(상태 줄에 '대화 n곳'). 코드가 올리는 목표는 코드에서 따로 고침.
- **시작 조건**(받는 방식이 '자동 시작'일 때): 지역·x/z·반경. `그림에서 자리 찍기`를 누르고(또는 그냥) 아래 지역 그림을 클릭하면 그 자리가 시작 위치(지도 탭과 같은 지형 그림 + 출구·마을 참고 표시). **＋ 확대 / － 축소 / 전체 보기** 버튼(또는 휠, 오른쪽 버튼 끌기로 이동)으로 크게 보고 세밀한 자리를 찍음, 빨간 동그라미는 끌어서도 옮김, 마우스 자리 좌표 표시, 출구·마을·쉼터 이름 표시. 목표 '플래그'는 플래그 고르기 칸.
- **목표**: `+ 목표: 아이템 모으기 / 몬스터 처치 / 횟수 / 이야기 플래그`. 아이템은 목록에서, 몬스터는 ID 앞부분(`meadow` = meadow_* 전부, 목록에서 골라 채움), 플래그는 코드·대화·컷씬이 세우는 키 목록에서 고르거나 직접 입력. ↑↓ 순서, × 지우기. 목표 ID는 대화 액션 '퀘스트 목표 진행'이 가리키는 값.
- **보상**: 일반 EXP·생활 EXP·골드, `+ 아이템`(아이템·개수), `+ 레시피`. 아래에 게임이 보여 줄 보상 문장 미리보기.
- **결과 분기**(선택): `+ 결과` → 키·이름·그 결과만의 보상. 대화 액션 '퀘스트 완료(보상)'의 '결과' 칸에서 고름(예: 짐을 돌려주고 사례 받기 / 거절).
- **아래 왼쪽 검증**: 없는 아이템·몬스터·레시피·의뢰인·지역, 겹친 목표 ID, 목표 없음, 자동 시작인데 시작 조건 없음, 음수 값 = 오류. 설명·표시 글자 비어 있음, 세우는 곳 없는 플래그, 횟수 목표를 올리는 액션 없음, NPC 의뢰인데 어떤 대화에도 '퀘스트 수락'이 없음 = 경고.
- **아래 오른쪽 쓰이는 곳**: 이 퀘스트를 쓰는 대화 노드(수락·목표 진행·완료·조건·선택지 조건)와 컷씬 단계. **더블클릭하면 그 대화의 그 노드 / 그 컷씬으로 이동**.
- `게임에서 실행`: 저장 뒤 게임을 켜서(진행 단계 C) 이 퀘스트를 받은 상태로 시작하고 퀘스트 기록(J)을 열어 줌. `이 퀘스트 지우기`: 파일 삭제(쓰는 곳이 있으면 몇 곳인지 먼저 알려 줌). 저장 `Ctrl+S`, 실행 취소 `Ctrl+Z` / 다시 `Ctrl+Y`.
- 저장할 때 키 순서를 고정하고 숫자를 정수로 정리해 씁니다(`QuestDB.normalized`). 손으로 쓴 파일을 에디터에서 한 번 저장하면 줄 배치가 바뀔 수 있지만 값은 같습니다.

## 노드 7종

| 노드 | 하는 일 | 출력 |
|---|---|---|
| 시작 | 진입점, 그래프당 하나(지울 수 없음) | 다음 |
| 대사 | 화자 + 대사 (게임에서 자동 줄바꿈) + 표정(초상화 그림, 화자에 등록된 것 중 선택, 기본값 비움) | 다음 |
| 선택지 | 선택지별 분기. 선택지마다 "조건이 맞을 때만 보이기" 가능 | 선택지마다 하나 |
| 조건 | 상태를 **조회만** 해서 분기: 플래그 / 퀘스트 상태 / 아이템 개수 / 골드 / 이벤트 완료 | 참 · 거짓 |
| 액션 | 허용 목록만: `set_flag`, `quest_accept`, `quest_advance`, `quest_complete`(보상은 퀘스트 데이터), `mark_event_complete`, `learn_recipe`, `receive_camper`, `cat_join`(고양이 동행 시작 + 호감도), `give_map`(지역 지도 주기) | 다음 |
| 컷씬 호출 | `data/cutscenes/*.json` 컷씬(위 컷씬 탭에서 작성)을 재생하고 끝나면 진행. 카메라는 고정 탑다운 그대로 | 다음 |
| 종료 | 대화를 끝내고 조작 반환. 선택적으로 이벤트 완료 기록(재생해도 한 번만) | — |

대사·조건·사용자 입력을 코드로 실행(`eval`/`Expression`)하는 경로는 없습니다. 같은 퀘스트 수락·보상은 다시 재생해도
중복 적용되지 않습니다(QuestManager가 상태로 막음).

## 데이터 (버전 1, UTF-8 JSON)

```
data/dialogues/<dialogue_id>.json   대화 (version, dialogue_id, metadata{title,tags,notes}, start_node_id, nodes, connections, editor_positions)
data/quests/<quest_id>.json         퀘스트 (목표·보상·결과 분기·시간 제한·반복·현장 사건 트리거)
data/cutscenes/<cutscene_id>.json   컷씬 (version, cutscene_id, title, notes, skippable, steps — 단계 종류·필드는 scripts/dialogue/cutscene_data.gd STEPS)
data/story.json                     새 게임 때 재생할 컷씬 순서 {"new_game": [...]}
data/speakers.json                  화자 ID → 표시 이름, NPC가 여는 대화(talk), 대화창 초상화 그림 경로(portrait, 생략 시 assets/portraits/<id>.png)
```

- 연결은 `connections`에만 저장하고 노드 ID로 잇습니다(표시 이름·위치를 바꿔도 끊기지 않음).
- 형식 설명은 `scripts/dialogue/dialogue_data.gd`, `scripts/game/quest_db.gd`, `scripts/dialogue/cutscene_runner.gd` 맨 위 주석.
- 내보내기(export) 빌드를 만들 때는 내보내기 설정의 "리소스가 아닌 파일 포함"에 `data/*.json`을 넣어야 합니다(아직 내보내기 설정 없음).

## 검증 방법과 결과

- **실제 Godot 4.7.2 에디터 안에서** 플러그인을 띄워 자동 점검(`DIALOGUE_EDITOR_SELFTEST=<캡처 폴더>` 환경 변수로 에디터 실행):
  열기 → 속성 → 미리보기(퀘스트 '받지 않음'이면 의뢰 분기, '목표 달성'이면 보고 분기) → 새 대화를 7종 노드로 작성 →
  오타 퀘스트 ID·연결 없는 선택지를 검증기가 찾음 → 수정 후 오류 0 → 숨김 선택지·컷씬 단계 미리보기 →
  실행 취소/다시 → 복사/붙여넣기 → 노드 이름 변경 후 연결 유지 → 저장 → 다시 열기 후 **노드·연결·문장·위치 동일** →
  한글·줄바꿈 보존 → 밖에서 바뀐 파일은 덮어쓰기 전에 확인 → **컷씬 탭**: 인트로 열기 → 새 컷씬에 단계 10종 추가 →
  빈 문장·플래그 키 오류 검출 → 수정 후 오류 0 → 순서 바꾸기·실행 취소·다시 → 저장·다시 열기 동일 → 새 게임 순서 추가(복원) →
  미리보기 끝까지 재생 → **몬스터 AI 탭**: 비선공 그래프 열기·검증 0 → 시뮬레이션(가만히 = 어슬렁, 동족 부름만 = 어슬렁, 맞음+사정거리 = 덮치기 /
  선공 그래프: 동족 부름 = 합류, 가까움 = 싸움 시작 거쳐 쫓기) → 새 그래프에 조건·행동 추가 → 연결 없는 예/아니오 검출 → 수정 → 시뮬레이션 →
  종류 바꾸기·실행 취소·다시 → 저장·다시 열기 동일 → 게임 쪽 로더가 같은 값 → 몬스터에 배정(monsters.json +1줄, 숫자 그대로) → 해제하면 원래 글자 그대로.
  → **지도 표시물 탭**(Map 화면): 초원 지도 열기·검증 0 → 캔버스 클릭으로 아이콘 놓기 → 아이콘·글자 바꾸기, 옮기기 → 실행 취소·다시 → 필드 드롭을 캔버스 클릭으로 → 없는 상점 검출·수정 → 저장·다시 열기 동일 → 게임 쪽 MapDB가 같은 값 → 파일 원래대로.
  → **퀘스트 탭**: 로사 의뢰 열기·검증 0, 쓰이는 곳에 로사 대화의 수락 액션 → 들어 있는 퀘스트 9개 전부 오류 0 → 잘못된 ID 거부·새 현장 사건 만들기 → 목표 4종 추가 → 없는 아이템·없는 몬스터·겹친 목표 ID·시작 조건 없음 검출 → 수정 후 오류 0 → 시작 자리를 지역 그림 클릭으로 → 보상 아이템·결과 분기 → 목표 추가·실행 취소·다시 → 저장·다시 열기 동일 → 게임 쪽 QuestDB가 같은 값(자동 시작·결과 보상·보상 문장) → 지우기.
  → **지역 배치 탭**(Map 화면): 초원 열기·검증 0 → 시작 위치 클릭 선택 → 옮기기·실행 취소·다시 → 몬스터 클릭으로 놓기 → 없는 몬스터 종류·없는 도착 지점 검출·수정 → 길 점 추가 → 저장·다시 열기 동일 → 게임 쪽 RegionDB가 같은 값 → 파일 원래대로.
  → **쉬운 사용 보강**(2026-10-25): 미리보기 끝 설명에 조건 1개 + 바꿔 보기 버튼 → 버튼으로 테스트 상태가 '목표 달성'이 되어 보고 분기 열림 → 플래그 모음에 게임 코드·대화 출처 → 플래그 목록·도움말 창 열기 → 퀘스트 시작 자리 그림 ×3 확대 후 0.1 m 단위로 찍기.
  → 목표 ID 바꾸기: 알현 퀘스트 main_1 → 이름 바꿈 → 왕 대화 act_met 참조가 따라 바뀜 → 되돌림 → 파일 원래대로.
  **73개 항목 모두 통과**.
  캡처: `captures/dialogue_editor/`.
- 게임 쪽은 `--tour=quest`로 같은 데이터를 실제 대화창에서 재생(아래 README 캡처 재생성 참고).
- 검증은 클라우드 컨테이너의 소프트웨어 렌더러(xvfb)에서 했습니다. **실제 Windows 에디터에서의 마우스 조작감(드래그·연결)은 직접 확인이 필요합니다.**
