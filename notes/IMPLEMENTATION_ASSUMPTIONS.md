# 구현용 임시 가정 (P0 + P1)

> 이 목록은 **개발 편의를 위한 임시 값**입니다. 정식 게임 규칙이 아니며 `docs/GDD.md`의 [확정] 사항을 바꾸지 않습니다.
> 기획이 정해지면 여기 적힌 값을 교체하면 됩니다.

## 지킨 [확정] 사항

- 엔진 Godot, 3D 월드를 저해상도·픽셀화 화면으로 표현 (GDD 3.1)
- **고정 탑다운 카메라, 카메라 회전 기능 없음** (3.1) — `C` 키는 투영(직교/원근)만 바꾸고 각도는 바꾸지 않음
- 캠핑카 실내는 별도 씬 (3.1, 9.1)
- WASD 이동, 마우스 방향 조준, **클릭 1회 = 공격 1회**(누르고 있어도 연속 공격 없음), ESC 일시정지 (4.1)
- **F = 캠핑카 외부 라이트 ON/OFF** (4.1, 10.3)
- 허리띠에 끼우는 등불 (10.3, 15.1)
- 게임 내 1분 = 현실 1초 [임시값 그대로 사용] (10.1)
- 걷기는 SP를 소모하지 않음, 달리기·공격은 SP 소모 (4.2)

## P0 전용 디버그 키 (최종 키 아님)

`1/2/3`, `M`, `P`, `N`, `T`, `L`, `I`, `K`, `C`, `X`, `-`/`=`, `F12`, `H`는 모두 비교 실험용입니다.
`GRAPHICS_PROTOTYPE.md` 5장에 있는 키(1/2/3, N, L, I, H, F)에 `M`, `P`, `T`, `K`, `C`, `X`, `-`/`=`, `F12`를 추가했습니다.
F 키와 다른 조작의 충돌, 인벤토리 키 등은 P1에서 정합니다.

## P1에서 지킨 [확정] 사항 (GDD v10.2)

- 클릭 1회 = 공격 1회, 무기 판정 영역이 몬스터 피격 영역에 **물리적으로 닿아야** 하고, 닿은 뒤 **TRPG 명중 판정**, 실패 시 피해 없음 (6.2)
- **치명타는 명중과 별도 판정** (6.2), 무기 주사위 피해, STR 배율은 **물리 주사위에만** 적용 (5.1, 6.2)
- 전투 로그 3단계: 1 아이콘(기본값) / 2 최근 한 줄 / 3 상세(명중·치명·주사위·피해 계산) (6.3)
- 인벤토리 열어도 게임은 멈추지 않음, ESC = 일시정지 (4.1)
- 몬스터 시체를 **직접 조사**해야 전리품 확인·획득, 자동 줍기 없음, 필요한 것만 선택, 해체 없음, 일정 시간 뒤 시체 소멸 (8.2)
- 슬롯 없는 중량 인벤토리, STR → 최대 소지 중량, 초과 시 이동 속도 감소, 한계 초과 시 획득 불가 (8.1)
- 캠핑카 창고: 별도 중량 제한, 개별 이동 + **소지품 전체 옮기기**, 도착 시 자동 보관 없음 (8.3)
- 선공 성향, 같은 종 합류, 활동 영역 이탈 시 추적 포기, 처치 후 게임 시간 경과 뒤 리스폰, 레벨 스케일링 없음 (7.2~7.5)
- 밤은 약간 더 위험 (10.2) → 선공 감지 범위 ×1.4
- 캠핑카 직접 운전, 문으로 들어가면 별도 실내 씬 (9.1)
- 간이침대 HP 10% [임시], 수면 시간 선택만큼 게임 시간 경과 (9.6, 10.1)
- 신수 고양이: 플레이어를 스스로 따라오며 동행 시작 → 캠핑카 획득 (2.3), 캠핑카 보유 시 실내에 항상 있음, 쓰다듬기, 간식 → 호감도 상승 (2.5)
- 실외 추종/실내 대기는 **같은 고양이** — 씬마다 최대 1마리만 생성 (2.5)
- 사망: 캠핑카 미보유 → 가까운 **몬스터 없는 안전 체크포인트**, 고양이 합류 후에는 곁에서 구조 정황 연출, 캠핑카 보유 → **캠핑카 실내** 기상 (2.4, 12.3)
- 일반 필드 사망: **고블린이 일부를 가져가고 나머지는 사망 장소에서 회수**, 복귀로 자동 회수되지 않음 (12.3)

## P2-5 퀘스트 — 지킨 [확정] 사항 (GDD 13)

- 획득 경로: **NPC 직접 대화**(로사), **게시판**(교역소), **탐험 중 현장 사건**(넘어진 짐수레)

- 같은 대화를 다시 재생해도 수락·보상은 **한 번만** (QuestManager 상태 + 이벤트 완료 플래그)
- 이야기 순서(왕의 의뢰 → 고양이 → 용 토벌 → 캠핑카 소원)는 건드리지 않음: 왕 대화·드래곤 퀘스트·고양이 첫 등장 컷씬은
  **테스트 데이터**(`test_only`)로만 두고 월드·진행 단계에 연결하지 않음

## P3-1 지역 이동 — 지킨 [확정] 사항 (GDD 11, 7.5, 9.4, 12.3)

## P3-4 채집·낚시·생활 숙련도 — 지킨 [확정] 사항 (GDD 14.1~14.3, 5.2, 5.4, 13.4)

- 일반 식물·광물은 **상호작용 → 짧은 채집 모션**으로 획득. 일부 희귀 자원은 **별도 조건**(달빛 꽃 = 밤에만), 모든 희귀 자원이 미니게임은 아님
- 낚시는 **자동 낚시** 또는 **직접 미니게임**을 고를 수 있고, **직접 하면 성공률·보상에서 이점**(희귀 어종 확률 3배, 생활 EXP 1.5배, 실력에 따라 성공)
- 채집·낚시로 **생활 EXP**와 **분야별 숙련도**가 쌓임. 숙련도는 **반복하면 자동으로 오르고**, 오르면 **성공률·효율**이 좋아짐
- 생활 EXP는 **생활 기술을 배우는 소비 자원**이고, 일부 기술은 **최소 숙련도 + 생활 EXP**가 필요
- 퀘스트 보상으로 **생활 EXP만** 주는 의뢰 가능(약초 납품)
- 1차 생활 콘텐츠만(채집·낚시), 농사·토지·집 짓기는 후순위로 손대지 않음
