# 맵 에디터 (Godot 에디터 위쪽 `Map` 화면)

기획자가 코드 없이 **지역을 직접 디자인·배치**하는 에디터입니다. 대화 에디터(`Dialogue`)와 별도의 메인 화면이며,
탭 두 개로 되어 있습니다.

| 탭 | 만드는 것 | 파일 |
|---|---|---|
| **지역 배치** | 지역 자체: 지형 모양(숲·연못·평지·언덕)·길·도시·**새 캐릭터 시작 위치**·출구와 도착 지점·체크포인트·이야기 장소·몬스터·NPC·채집·낚시터. 고정 던전은 칸 그림 | `data/regions/<지역 ID>.json` (런타임 `scripts/world/region_db.gd`, `visual_lab.gd`가 읽음) |
| **지도 표시물** | 플레이어가 모으는 지도의 지명·아이콘·메모와 얻는 방법 (대화 에디터에 있던 `지도` 탭을 그대로 옮김) | `data/maps/<지역>.json` (`map_db.gd`) |

플러그인: `addons/map_editor/` (에디터 전용, 게임 빌드에는 불필요). `project.godot`의 `[editor_plugins] enabled`에
`res://addons/map_editor/plugin.cfg`가 들어 있어야 보입니다(저장소에 포함).

## 여는 법

Godot으로 프로젝트를 열고 위쪽 가운데 `Map`을 누릅니다. 왼쪽 목록에서 지역을 고르면 가운데에 그 지역의 지형 그림이
(게임의 지도와 같은 그림, 북쪽이 위) 그려지고 그 위에 배치된 것들이 겹쳐 보입니다.

## 지역 배치 탭

### 그림 조작

- **클릭** = 가장 가까운 것을 고름(빨간 테두리), **끌기** = 옮김(놓으면 저장 대상이 됨). 그림 위 **＋ 확대 / － 축소 / 전체 보기** 버튼, 또는 **휠** = 확대/축소, **오른쪽/가운데 버튼 끌기** = 그림 이동. 오른쪽 끝에 마우스 자리의 x·z.
- 위쪽 **놓기** 줄의 버튼(`시작 위치`, `+ 몬스터`, `+ NPC`, … `+ 길`, `+ 길 점`)을 누른 뒤 그림을 클릭하면 그 자리에 새로 생깁니다. `Esc` = 취소.
- `선택 삭제` 또는 `Delete`(그림에 포커스가 있을 때) = 고른 것 지우기.
- 그림에 보이는 것: 빨간 화살표 = **시작 위치**(새 캐릭터가 깨어나는 자리, 화살표가 바라보는 방향), 연두 점 = 도착 지점, 흰 점 = 출구, 하늘색 ▲ = 체크포인트,
  노랑 = 이야기 장소(반경 원), 빨강 = 몬스터, 주황 = NPC, 연두 = 채집, 파랑 = 낚시터(부두 선), 노란 사각형 = 도시, 초록/파랑/모래색 원 = 숲/연못/평지, 갈색 원 = 언덕(높이 표시), 갈색 선 = 길(점 = 꺾이는 자리).

### 오른쪽 속성

- **지역**: 이름, 위험도(별 수), 설명, 세계 지도 위 자리(`map.origin`), 지형 크기(가로·세로 m, 가운데 기준), 지형 씨앗, 언덕 굴곡. 지형 값을 바꾸면 그림이 잠시 뒤 다시 그려집니다.
- **시작 위치**: x·z와 바라보는 방향(°, 0 = 북쪽 = 화면 위, 180 = 남쪽). 그림의 빨간 화살표를 끌어도 같습니다. 지우면 게임은 기본 자리(캠프 근처)를 씁니다.
- **고른 것**: 그 항목의 모든 필드가 그대로 나옵니다. 숫자는 스핀 박스, 켜고 끄기는 체크, `[x, z]`는 x·z 두 칸, 그 밖의 배열·사전은 JSON 글자. 아는 필드는 목록에서 고릅니다:
  몬스터 `kind`(= `data/monsters.json`), NPC `look`(`npc_rig.gd`의 외형)·`speaker`(`data/speakers.json`), 출구 `to_region`(지역)·`to_entry`(그 지역의 도착 지점 — 지역을 바꾸면 첫 도착 지점으로 맞춰짐), 이야기 장소 `flag`(퀘스트·코드가 아는 플래그 목록에서 고르거나 직접 입력).
  각도(`yaw`)는 도 단위로 보여 주고 파일에는 라디안으로 저장합니다.
- **도착 지점**: 다른 지역의 출구가 가리키는 이 지역의 자리. ID 버튼 = 고르기, `자리 찍기` = 그림 클릭으로 옮김, 아래 칸에 새 ID를 적고 `+ 추가`.
- **고정 던전**(`kind: dungeon`): 지형 대신 **칸 그림**(한 줄 = 한 행, 범례는 위에 표시) 글상자와 칸 크기 → `칸 그림 적용`. 던전은 그림 위 배치 대신 칸 그림으로 만듭니다.
- **랜덤 던전**(변덕의 미궁)은 층마다 새로 생성되므로 이름·설명만 고칩니다.

### 도구 줄

`새 지역 (복제)` = 지금 연 지역을 복제해 새 파일(ID·이름 입력; 먼저 저장해야 함) · `저장`(`Ctrl+S`) · `파일에서 다시 읽기`(변경 버리기) · `↶ ↷`(`Ctrl+Z` / `Ctrl+Y`) ·
`검증` · `게임에서 실행` = 게임을 띄워 **이 지역의 시작 위치**에 서서 시작(먼저 저장; 자동 투어처럼 진행 단계 C로 시작) · `플래그 목록`(모든 플래그와 켜는 곳·쓰는 곳) · `❓ 도움말`(쉬운 사용법). 이야기 장소의 `flag`는 플래그 고르기 칸(목록 + 새 이름 + 출처 설명).

### 검증 (아래 목록, 저장 때도 다시 검사)

⛔ 오류: 비어 있거나 겹친 ID, 없는 몬스터 종류, 없는 NPC 외형, 출구가 가리키는 지역/도착 지점 없음, 시작 위치가 지역 밖, 던전 칸 그림 줄 길이 다름·도착 칸 `S` 없음, 이름 비어 있음.
⚠ 경고: 지역 밖의 배치, 화자가 없는 NPC(대화가 안 열림), 플래그도 안내문도 없는 이야기 장소, 시작 위치 없음. 오류가 있어도 저장은 되지만 상태 줄에 개수가 남습니다.

### 저장되는 모양

게임이 읽는 JSON 그대로(들여쓰기 2칸, 정수는 정수로). 편집 중 생긴 `_`로 시작하는 임시 키는 빼고 씁니다(던전 범례 `_legend`는 남김).
저장하면 게임 쪽 `RegionDB`·`MapDB` 캐시를 비워 에디터 안의 다른 탭(퀘스트 시작 조건 그림, 지도 표시물)도 새 지형을 씁니다.

## 지도 표시물 탭

대화 에디터 `지도` 탭의 내용과 같습니다 → [`DIALOGUE_EDITOR.md`](DIALOGUE_EDITOR.md)의 "지도 탭" 절.

## 자동 점검

대화 에디터 자체 검사(`DIALOGUE_EDITOR_SELFTEST=...`)가 `Map` 화면으로 넘어와 두 탭을 같이 검사합니다:
초원 열기·검증 0 → 빨간 화살표 클릭으로 시작 위치 선택 → (6, 2)로 옮기기·실행 취소·다시 → 몬스터를 클릭으로 놓기 → 없는 몬스터 종류 검출·수정 →
없는 도착 지점을 가리키는 출구 검출·수정 → 길 끝에 점 추가 → 저장·다시 열기 동일 → 게임 쪽 `RegionDB`가 옮긴 시작 위치·새 몬스터를 봄 → 파일 원래대로.
캡처: `captures/dialogue_editor/editor_50_region_meadow.png`, `editor_51_region_edited.png`.

## 구조

```
addons/map_editor/
  plugin.cfg / plugin.gd       EditorPlugin: Map 메인 화면(탭 2개), '게임에서 실행' 파일 전달(user://dialogue_playtest.json {"region_id"})
  region_editor_panel.gd       지역 배치 탭 (RegionEditorPanel): 그림·속성·검증·실행 취소·저장
  map_editor_panel.gd          지도 표시물 탭 (MapEditorPanel) — dialogue_editor에서 옮김
scripts/world/region_db.gd     reload / path_for / expanded(던전 칸 그림 → 배치) / save
scripts/game/map_db.gd         terrain_image_of(지역 사전) — 저장 전 문서로 그림을 그림, clear_caches
scripts/core/bootstrap.gd      _check_dialogue_playtest(): region_id → 그 지역의 시작 위치에서 시작
```

## 아직 안 한 것

- 지형의 흩뿌림(`scatter` 밀도)·도시 안의 집 배치·`features`(장식 구조물)는 JSON 글자 칸으로만 고침.
- 여러 항목 한꺼번에 고르기·복사, 그림 위에서 반경 끌어 늘리기, 지역 간 출구 ↔ 도착 지점 자동 짝 만들기.
- 게임 쪽 코드에 박힌 자리(오두막 `visual_lab.gd` `HUT_POS`, 캠프)는 아직 에디터에서 못 옮김.
