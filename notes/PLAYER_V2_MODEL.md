# 주인공 새 원형 v2 — Blender 정지 모델 제작 로그

기준: 사용자 제공 *Healing_RPG_Player_Character_Blender_Brief_v1* (귀엽고 푸근한 플레이어 캐릭터, 정지 모델 검증 우선).
이번 작업은 **정지 모델 · GLB · 4시점 렌더 · 실루엣 · 게임 화면 비교**까지입니다. 브리프의 "개발 진행 금지 조건"에 따라
**게임 속 주인공은 아직 바꾸지 않았고**, 리깅·애니메이션·스프라이트 교체도 하지 않았습니다(승인 후 진행).

## 실제로 Blender를 실행했는가

예. 이 작업 환경에서 PyPI의 `bpy` 5.2.2 LTS(Blender를 파이썬 모듈로 빌드한 공식 패키지)로 아래 스크립트를 실행해
모델링·Cycles 렌더·GLB 내보내기·.blend 저장을 했습니다. GUI가 있는 Blender 앱을 띄운 것은 아니며, 같은 스크립트를
사용자 PC의 Blender로 그대로 재현할 수 있습니다.

```bat
:: Blender 4.2 이상 설치되어 있으면 (C:\Game\denial 에서)
blender -b -P tools/blender/player_v2_build.py -- art_src/player_v2 assets/characters/player_v2/player_v2.glb
:: 또는 Python 3.13 + pip install bpy pillow
python tools/blender/player_v2_build.py art_src/player_v2 assets/characters/player_v2/player_v2.glb
:: Godot 게임 화면 비교 캡처
Godot.exe --path C:/Game/denial -- --tour=charcompare --capture-dir=C:/Game/denial/captures/player_v2
```

## 조형 · 재질

- **머리**: 큰 대머리, 머리카락·헤어라인 없음. 작은 귀.
- **얼굴**: 웃는 눈(^ ^), 굵고 부드럽게 처진 눈썹, 크고 둥근 코, 볼살 + 분홍 볼터치, 작게 웃는 입.
- **콧수염**: 코 아래 큰 덩어리 2개 + 끝이 말린 작은 덩어리 2개(4개). 턱수염 없음. 눈과 코를 가리지 않음.
- **의상**: 흰 민소매 런닝(배를 덮는 한 덩어리, 목선까지 이어짐), 앞이 열린 빨간 버펄로 체크 셔츠(앞섶은 배의 곡면을 그대로 따라감, 짙은 테두리), 팔꿈치까지 걷은 소매, 갈색 벨트, 올리브 카고 바지 + 옆 주머니, 둥글고 큰 갈색 워크 부츠(밑창·발목 둘레·끈).
- **팔다리**: 짧고 굵게, 손은 단순한 둥근 덩어리.
- **재질**: Base Color만(Principled, 금속성 0, 거칠기 0.8~0.9). 텍스처는 체크무늬 8×8 한 장(최근접 필터). 피부 텍스처·노이즈·광택 없음.
- **무기·등불 없음**: 정지 원형 검수용. 철검·등불 허리띠는 기존 장비 표시 방식대로 나중에 붙입니다.
- **Godot 비교용 셰이딩**: 게임 소품과 같은 툰 확산(`DIFFUSE_TOON`, 스페큘러 끔, 거칠기 0.06)으로 바꿔서 놓았습니다.

## 수정 이력 (렌더·게임 화면을 보고 고친 것)

1. 눈썹이 안쪽으로 내려가 화난 인상 → 바깥쪽이 처지게 뒤집고 조금 올림.
2. 점 눈이 멍해 보임 → 아래쪽을 피부색 눈꺼풀로 덮어 웃는 눈.
3. 런닝이 배·가슴 두 덩어리로 나뉘어 눈사람처럼 보임 → 위쪽이 좁아지는 한 덩어리로 교체.
4. 셔츠 앞섶이 막대처럼 떠 있음 → 배 곡면에서 잘라 낸 띠로 다시 만들어 몸에 밀착(체크무늬 + 안쪽 짙은 테두리).
5. 게임 크기에서 체크무늬가 잘게 부서져 노이즈 → 체크 칸을 키우고 짙은 색 대비를 낮춤.
6. 40° 위에서 보면 콧수염이 코에 가려 작게 보임 → 콧수염 덩어리를 키우고 앞으로 더 냄. 눈도 조금 키움.

## 합격 기준 자체 점검 (판단은 사용자 몫)

| 기준 | 상태 |
|---|---|
| 대머리·콧수염·런닝·붉은 체크 셔츠·카고 바지·워크 부츠 유지 | 모두 있음 |
| 머리카락·턱수염·갑옷·무기 등 참고 이미지 요소 | 넣지 않음 |
| 현재보다 귀엽고 푸근한가 | 렌더에서는 분명히 그렇다고 보지만, 최종 판단은 사용자 확인 필요 |
| 게임 화면에서 콧수염과 눈 구분 | 3배 확대 캡처 기준 눈썹·눈·코·볼·콧수염이 각각 다른 픽셀 덩어리로 보임. 머리가 화면에서 약 22픽셀이라 눈은 1~2픽셀 |
| 캠핑카·배경과 크기/색/픽셀 밀도 | 키를 기존과 같게 맞춤. 같은 픽셀 파이프라인으로 그려짐 |

## 남은 문제 · 다음 단계 (승인 후)

- 게임 화면의 v2는 **실시간 3D**라서, 베이크 스프라이트인 기존 주인공의 짙은 1픽셀 외곽선이 아직 없습니다. 교체할 때 같은 베이크 파이프라인(`SpriteBaker`)으로 구우면 외곽선·8방향 시트가 같은 방식으로 나옵니다.
- 기존 주인공 스프라이트가 가까이(1.65 m 안) 있으면 그 가림 실루엣이 옆 3D 물체 위에 노랗게 비칩니다. 비교 캡처는 두 캐릭터를 2 m 떨어뜨려 피했습니다(기존 스프라이트 쪽 동작, v2와 무관).
- 체크무늬는 게임 크기에서 여전히 조금 자글자글합니다. 실루엣을 우선해 더 단순하게 할지(단색 + 굵은 줄) 결정 필요.
- 승인되면: 관절 분리(팔·다리 피벗) 또는 리깅 → 걷기·공격·사용 동작 → 장비 표시 → 스프라이트 베이크 교체 순서로 진행합니다.
