# 주인공 새 모델 v3 — Blender 정지 모델 (승인 대기)

기준: 사용자가 준 캐릭터 시트(정면·측면·후면). 이 단계는 **모델링만** 합니다. 게임에 넣기, 리깅, 애니메이션,
스프라이트 교체는 **사용자 승인 후**에 합니다. 지난 v2(구체를 이어 붙인 원형)와 게임 비교 투어는 반려되어 지웠습니다.

## 실행 방법

이 작업 환경에서는 PyPI의 `bpy` 5.2.2 LTS(Blender를 파이썬 모듈로 빌드한 공식 패키지)로 실행했습니다.
Blender 앱 화면을 띄운 것은 아니며, 같은 스크립트를 PC의 Blender로 그대로 재현할 수 있습니다.

```bat
:: Blender 4.2 이상 (C:\Game\denial 에서)
blender -b -P tools/blender/player_v3_build.py -- art_src/player_v3
:: 또는 Python 3.13 + pip install bpy pillow
python tools/blender/player_v3_build.py art_src/player_v3
```

| 파일 | 내용 |

## 만드는 방식 (v2와 다른 점)

- **메타볼**(서로 녹아 붙는 덩어리)로 큰 형태를 만든 뒤 메시로 바꿨습니다. 그래서 어깨→소매, 소매 안의 팔→손목→주먹,
  엉덩이→다리가 이음매 없이 한 덩어리로 이어집니다.
- 색 영역마다 하나의 연결된 메시입니다: 피부(머리·턱·팔·주먹), 수염, 눈썹, 셔츠(몸통·어깨·반소매), 티셔츠, 청바지, 부츠, 밑창.
- 작은 부위는 따로 둡니다: 코, 눈, 귀(+귓속), 손가락 마디 4개와 엄지(주름이 보이도록), 셔츠 깃, 걷은 소매 단, 셔츠 앞섶.
- 셔츠 앞섶은 티셔츠 배 곡면을 1.04배로 키워 잘라 낸 판이라 배에 그대로 붙어 있습니다. 밑단은 평면으로 잘라 반듯합니다.
- 얼굴 부위(코·눈·눈썹)는 머리 표면에 광선을 쏴서 맞은 자리에 놓았습니다. 그래서 떠 있거나 파묻히지 않습니다.
- 재질은 Base Color만 씁니다(금속성 0, 거칠기 0.85). 체크무늬는 8×8 텍스처 한 장을 월드 좌표 박스 매핑으로 입혔고, 앞섶은 정면 투영입니다. 반복 길이는 9 cm로, 몸 폭에 약 7칸이 들어가 시트와 비슷합니다.

## 이전 지침서와 다른 점 (사용자 시트를 따름)

첫 지침서(Healing_RPG_Player_Character_Blender_Brief_v1)와 다르게, 이번 시트를 기준으로 했습니다.
- **턱수염 있음**: 지침서는 "콧수염만, 턱수염 없음"이었습니다.
- **회색 티셔츠**: 지침서는 흰 민소매였습니다.
- **청바지**: 지침서는 카고 바지였습니다.
- **볼터치·웃는 눈 없음**: 점 눈입니다.

## 알려진 한계

- 삼각형 약 16만 개(GLB 3.1 MB)로 검토용 해상도입니다. 게임에 쓸 때는 줄이고(리메시·데시메이트) 리깅에 맞게 다시 정리합니다.
- 눈썹 아래쪽 가장자리가 덩어리를 이은 흔적으로 살짝 울퉁불퉁합니다.
- 게임 카메라(40° 위)에서는 원근 때문에 눈썹 안쪽이 내려가 보여 약간 엄해 보입니다.
- 손가락은 주먹 위에 얹은 덩어리이고, 손 모양을 바꿀 수 있는 구조(관절)는 아닙니다.
