# P0 시각 비교 결과

> **검증 환경 (중요):** Godot 4.7.2-stable, 클라우드 컨테이너의 **소프트웨어 렌더러**
> (Mesa llvmpipe, Vulkan 1.4 Forward+ / OpenGL 4.5 Compatibility), Xvfb 1280×720.
> 실제 GPU·모니터로는 실행하지 않았습니다. 아래 평가는 자동 캡처 투어의 **정지 이미지 18장**과
> **녹화 영상 1개(14초, 30fps)에서 뽑은 프레임**을 보고 쓴 것입니다. 실시간 체감(특히 떨림)은
> 사용자가 직접 실행해서 최종 판단해야 합니다.

캡처 파일은 [`captures/p0_baseline/`](../captures/p0_baseline/)에 있습니다. **주의:** 이 폴더의 이미지는 이후 비주얼 방향 수정([`VISUAL_DIRECTION.md`](VISUAL_DIRECTION.md)) 뒤 새 아트로 다시 찍은 것이라, 아래 문장 중 첫 블록형 아트에 대한 묘사(예: 인물 텍셀 크기, 지면 색면)는 현재 이미지와 다를 수 있습니다. 렌더 파이프라인·떨림·조명 구조에 대한 결론은 그대로 유효합니다. 파일 이름의 번호는 `GRAPHICS_PROTOTYPE.md` 4장의 테스트 장면 번호입니다.

## 1. 렌더 모드별 품질

같은 위치(캠핑카 앞)에서 촬영: `03_day_camper_PXL-COARSE`, `06a_compare_PXL-SOFT`, `06b_compare_3D-NATIVE`,
`06c_compare_M2_scaling3d_nearest_320`, `06d_compare_M3_palette_dither_PXL-COARSE`.

| 모드 | 내부 해상도 | 관찰 |
|---|---|---|
| **PXL-COARSE** (M1) | 320×180 → ×4 | 가장 "픽셀 게임"처럼 보입니다. 인물 높이 약 22~24 텍셀로, 빨간 재킷·배낭·머리·검까지 구분됩니다. 나무와 캠핑카 윤곽이 깔끔한 계단 모양으로 떨어집니다. 그림자 가장자리도 텍셀 단위로 끊겨 스타일에 맞습니다. 작은 소품(풀 다발, 장작)은 2~4 텍셀이라 형태보다 점으로 읽힙니다. |
| **PXL-SOFT** (M1) | 640×360 → ×2 | 디테일이 확 늘어 캠핑카 줄무늬·창틀·바퀴 허브가 또렷합니다. 대신 "픽셀아트"보다는 "저해상도 3D"로 보입니다. 실내 장면은 COARSE보다 판독성이 확실히 좋습니다(`07c`). |
| **3D-NATIVE** | 1280×720 | 대조군. 같은 모델이 매끈한 로우폴리 3D로 보입니다. MSAA를 끈 상태라 경계 계단이 약간 남습니다. 소프트웨어 렌더에서 FPS가 가장 낮았습니다. |
| **M2 3D 스케일링 nearest** | 320×180 상당 | M1 COARSE와 **눈으로 구분이 안 될 만큼 같습니다**(`06c` vs `03`). 문서 예상대로 두 방식이 수렴합니다. M2는 뷰포트가 출력 해상도라 2D 요소를 같은 뷰포트에 섞을 때만 차이가 납니다. P1에서는 단순한 **M1을 권장**합니다. |
| **M3 팔레트+디더** | M1 위 후처리 | 첫 설정(6단계, 강도 0.6)은 잔디 전체에 디더 노이즈가 깔려 판독성이 떨어져 **8단계·강도 0.35로 낮췄습니다**. 지금은 잔디·흙길 경계에 약한 체크 무늬만 생깁니다. 레트로 느낌은 더해지지만 가독성 이득은 없습니다. **기본 OFF 유지 권장.** |

## 2. 캐릭터·차량 가독성과 비율

- **인물** (`01`, `03`): 피치 50°, 화면 세로 11m 기준으로 COARSE에서도 사람으로 읽힙니다. 등 뒤 배낭과
  얼굴 쪽 셔츠 덕분에 앞뒤 방향이 구분됩니다. 첫 설정(피치 55°, 13m)에서는 너무 위에서 내려다봐 머리와
  어깨만 보였기 때문에 **50°/11m로 조정**했습니다.
- **캠핑카** (`03`): 흰 차체, 운전석 위 알코브, 측면 청록/주황 줄무늬, 창문, 문, 2+1 바퀴 덕분에 **박스나 마차가
  아닌 현대 RV로 읽힙니다.** 위에서 보는 각도라 지붕 면적(태양광 패널, 에어컨)이 화면을 많이 차지합니다.
  인물:차량 비율은 약 1.75m : 7.2m로 화면에서도 자연스럽습니다.
- **슬라임**: 청록 몸체 + 흰 눈 + 정수리 혹. 낮의 초록 지면과 색이 겹치지 않고, 밤에도 달빛에서 밝게 보입니다(`04b`).
- **전투 위치 판독**: 인물·적의 위치는 COARSE에서도 명확합니다. 다만 **공격 방향(검 휘두르기)은 4~6 텍셀짜리
  검 하나라 COARSE에서는 약합니다.** P1에서는 휘두르기 궤적 이펙트나 방향 표시가 필요해 보입니다(이번 P0 범위 밖).

## 3. 이동 중 픽셀 떨림

- **픽셀 스냅 카메라(기본 ON)**: 카메라를 렌더 텍셀 격자에 맞추고 남는 오차는 화면을 화면 픽셀 단위로 밀어
  보정합니다. 이론상 정적인 지형·나무·캠핑카는 프레임 사이에 텍셀 패턴이 바뀌지 않습니다.
- 녹화 영상 `09_walk_day_night_14s.mp4`(COARSE → SOFT → NATIVE → 밤 COARSE) 프레임에서 지형 전체가 깜빡이거나
  튀는 현상은 **보이지 않았습니다**.
- 움직이는 대상(플레이어, 슬라임)은 스냅되지 않으므로 자체 윤곽이 걸음마다 1텍셀씩 바뀝니다. 픽셀 게임에서는
  정상 범위입니다.
- **`K`로 스냅을 끄고 직접 비교해 볼 것을 권장합니다.** 저는 영상을 실시간 재생해 보지 못했습니다.
- 원근 투영(`C`)에서는 텍셀 스냅이 의미가 없어 꺼지므로, 원근에서는 떨림이 커질 것으로 예상합니다(미검증).

## 4. 그림자

- 태양(방향광) 그림자: PSSM 2분할, 최대 75m. COARSE에서 그림자 경계가 텍셀 단위로 깔끔합니다. 나무 그림자가
  길을 덮을 때 인물 위치는 여전히 읽힙니다(`02`).
- **등불 그림자**: 처음에는 플레이어 자신의 몸이 허리 등불의 그림자를 드리워 거대한 어두운 쐐기가 따라다녔습니다.
  `shadow_caster_mask`로 플레이어 메시를 제외해 **해결**했습니다.
- **남은 문제**: 등불 바로 옆에 바위·나무가 있으면 그 물체가 화면 끝까지 이어지는 긴 그림자 쐐기를 만듭니다(`05a`).
  물리적으로는 맞지만 시선을 끕니다. 등불 그림자를 끄거나 범위를 줄이는 방안을 비교해야 합니다.
- 캠핑카 현관등의 그림자도 같은 이유로 꺼 두었습니다. 헤드라이트(스포트) 그림자는 켜져 있습니다.

## 5. 조명 · 낮/밤

- **밤 + 빛 없음** (`04b`): 달빛과 푸른 환경광 덕분에 화면 전체가 판독 가능합니다. 슬라임·캠핑카·길이 보입니다.
  "불필요하게 극단적으로 어둡게 하지 않는다"는 지침에는 맞지만, **광원의 필요성을 느끼기에는 조금 밝을 수 있습니다.**
  `day_night_controller.gd`의 `AMBIENT_NIGHT`, 밤 `ambient_light_energy`(0.42)로 조정할 수 있습니다.
- **개인 등불** (`04`): 반경 약 8m의 따뜻한 원광. 인물 주변 흙길과 근처 적을 구분하기에 충분합니다.
  화면 전체가 뿌옇게 번지지 않습니다(glow 약하게 설정).
- **캠핑카 F 라이트** (`05a`→`05b`, `05c`): 헤드라이트 2개(스포트, 그림자 ON), 현관등, 후미등이 켜집니다.
  캠핑카 앞 캠프 영역이 밝아져 분위기가 확실히 달라집니다. Forward+에서는 빔 윤곽이 은은하고,
  **Compatibility 렌더러에서는 더 밝고 빔 원뿔이 뚜렷합니다**(렌더러 간 조명 차이 — 최종 렌더러 결정 시 고려).
- 시계는 현실 1초 = 게임 1분이며, 05:00~07:00과 18:00~20:00에 노을 톤으로 서서히 바뀝니다(`T`로 정지 가능).

## 6. 가림(나무 뒤 캐릭터)

`02_*` 세 장은 같은 위치에서 가림 보조 방식만 바꿔 찍었습니다.

| 방식 | 관찰 |
|---|---|
| **실루엣**(기본) | 수관에 가려진 부분만 밝은 실루엣으로 표시합니다. COARSE에서도 위치와 자세가 보입니다. 자기 가림(배낭 뒤 팔 등)으로 인한 오표시는 셰이더 바이어스로 제거했습니다. 적은 붉은 실루엣으로 표시합니다. |
| **수관 투명화** | 플레이어 남쪽(카메라 쪽) 나무의 수관이 30%로 반투명해집니다. 겹친 구체끼리 투명 정렬 얼룩이 생기지만 판독에는 지장이 없습니다. |
| **끔** | 큰 활엽수 뒤에서 인물이 완전히 사라집니다. **가림 보조는 필수**로 판단합니다. |

## 7. 실내 판독성

`07a`(밤), `07b`(낮), `07c`(낮 SOFT). 9×4.4m 방 전체가 한 화면에 들어옵니다(외부 차체 폭은 2.4m — 마법 확장 느낌 실험).
카메라 쪽 벽을 0.45m로 잘라 내부가 가려지지 않습니다. 간이침대(파란 천·흰 베개·주황 담요), 주방(싱크대·2구 버너·냄비),
냉장고, 작업대(바이스·공구·타공판), 수납 선반, 식탁이 COARSE에서도 실루엣과 색으로 구분됩니다.
낮에는 창문이 밝게 빛나고 차가운 보조광이 들어오며, 밤에는 따뜻한 천장 조명만 남습니다.
야외와 같은 텍셀 밀도라 장면 전환 시 이질감이 없습니다. 작은 소품(공구, 컵)은 COARSE에서 점에 가깝습니다.

## 8. 렌더 방식에 대한 결론 (제안 — 확정 아님)

1. **M1(SubViewport 확대) + 픽셀 스냅 카메라**를 기본 파이프라인 후보로 권장합니다. M2는 결과가 같고 이점이 없습니다.
2. 해상도는 **PXL-COARSE(320×180)가 스타일상 가장 매력적**이지만, 전투 방향 판독과 작은 소품에는 불리합니다.
   1280×720 출력에서 정수 배율은 ×4/×2뿐이므로, 최종 목표 해상도(예: 1920×1080이면 480×270 ×4, 640×360 ×3)를
   정한 뒤 중간 밀도를 다시 비교해 볼 가치가 있습니다.
3. 가림 보조는 **실루엣 방식**을 우선 권장합니다.
4. 팔레트/디더 후처리는 보류합니다.

**보류 신호 점검**

| 보류 신호 | 관찰 |
|---|---|
| 걷기 시작하면 지형 전체가 튀고 반짝임 | 녹화 프레임에서는 관찰되지 않음 — **실기 확인 필요** |
| 작은 인물과 몬스터의 공격 방향이 구분되지 않음 | **부분 해당**: 위치는 명확하지만 COARSE에서 검 휘두르기 방향이 약함 |
| 저해상도에서 캠핑카가 판독 불가 상자 | 해당 없음 |
| 밤에 빛이 번져 화면이 뿌옇고 캐릭터가 안 보임 | 해당 없음 |
| 나무·지붕에 가려 캐릭터가 자주 사라짐 | 가림 보조 끔일 때만 해당 → 실루엣으로 해결 |

**판정: 조건부 통과(사용자 실기 확인 대기).** 기술적으로 요구 항목은 모두 동작합니다. 다만 "아트 스타일로 쓸 만한가"와
"떨림이 거슬리는가"는 실제 GPU에서 직접 걸어 보고 결정해야 합니다. P1로 넘어가기 전에 확인할 것:

1. 실제 PC에서 F5 → `1`/`2`/`3` 비교, `K` 스냅 ON/OFF로 떨림 비교.
2. 밤 밝기(`N`)가 "조명이 중요하다"고 느낄 정도인지.
3. COARSE에서 공격 방향 판독이 충분한지, 아니면 해상도를 한 단계 올릴지.
